## 🔄 节点列表有变化，先更新订阅

旧配置不一定包含最新的节点信息。

遇到节点名称变化、部分节点无法使用时，可以先在客户端更新订阅，查看是否出现错误提示，再结合站内公告判断下一步操作。

不要反复添加同一份订阅，以免留下多个难以区分的配置。

## 🗂️ 给配置起一个能认出来的名字

将配置命名为 `Connectigo`，比保留一串默认字符更方便查找。

如果客户端里同时保存了多份订阅，可以按服务名称分别命名。准备删除旧配置前，先确认当前正在使用的是哪一份。

**配置清楚，排查时就少一点猜测。**

## 📶 换了网络，重新看一次连接表现

家里的 Wi-Fi、手机热点和其他网络环境，连接表现可能不同。

在一个网络下可用的节点，换到另一个网络后也可能出现波动。此时可以检查本地网络，再测试其他可用节点，不必立即重装整个客户端。

## 🧩 每次只调整一项设置

连接异常时，同时修改多个选项，很容易弄不清究竟是哪一步起了作用。

可以按顺序检查：

1. 本地网络是否正常。
2. 套餐是否有效。
3. 订阅能否成功更新。
4. 更换节点后是否恢复。
5. 客户端是否显示明确的错误提示。

每完成一步就测试一次，保留有效的调整。

## 🔐 分享问题，隐藏凭证

需要反馈问题时，设备系统、客户端版本、发生时间和错误提示通常比一句“连不上”更有帮助。

发送截图或日志前，请隐藏：

- 个人订阅链接。
- 账号密码与访问令牌。
- 二维码中的订阅信息。
- 日志里不需要公开的个人内容。
